요청 하나가 지나가는 길

일반 조회 브라우저 → api → services → repositories → models → DB AI 질문 브라우저 → api → services → graph → nodes ─┬ tools → services → repositories └ rag → ai(embedder·vector_store·llm)
폴더 이름이 곧 계층입니다

api 는 HTTP 를 알고, repositories 는 DB 를 알고, ai 는 바깥 API 를 압니다. 서로의 일을 넘겨받지 않습니다. 어디를 고쳐야 할지 헷갈리면 "이건 누구의 일인가" 를 물어보면 됩니다.

정형과 비정형이 갈리는 지점

customers / products / purchases 숫자와 코드 → SQLAlchemy → Repository → Function Calling product_details / reviews 사람이 쓴 문장 → 청킹 → 임베딩 → 벡터 검색 → RAG

이 구분이 프로젝트 전체를 가릅니다. "구매액이 가장 높은 고객" 은 위쪽 길로, "환불 되나요" 는 아래쪽 길로 갑니다.

reviews.csv 는 원래 없었습니다

처음 purchases.csv 에는 rating 과 review 칸이 붙어 있었습니다. 정형과 비정형이 한 파일에 섞여 있으면 다루는 방법이 갈리지 않습니다. 그래서 pipeline/split_reviews.py 가 떼어냅니다.

import 부분

import csv 파이썬에 기본으로 들어있는 CSV 도구. 설치할 것이 없습니다.
from pathlib import Path 경로를 다루는 도구. 글자를 이어 붙이는 것보다 안전합니다.
우리 코드를 안 가져옵니다 app/ 을 하나도 부르지 않습니다. DB 가 아직 없어도 돌아갑니다. 가장 먼저 실행되는 파일이라 그렇습니다.

상수 부분

Path(__file__).parent.parent __file__ 은 지금 이 파일의 위치입니다. .parent 두 번이면 프로젝트 최상위 폴더입니다. 어느 폴더에서 실행하든 data/ 를 정확히 찾습니다.
DATA / "purchases.csv" Path 는 나눗셈 기호로 경로를 이어 붙입니다.
PURCHASE_COLUMNS 와 REVIEW_COLUMNS 이 두 줄이 곧 "무엇을 어디로 보낼지" 에 대한 답입니다. 앞에는 rating·content 가 없고, 뒤에는 quantity 가 없습니다.

함수 정의 부분

with open(...) as f 파일을 열고 블록이 끝나면 자동으로 닫습니다.
encoding="utf-8" 한글이 깨지지 않게 합니다.
newline="" csv 모듈을 쓸 때의 규칙입니다. 빼면 윈도우에서 빈 줄이 하나씩 끼어듭니다.
csv.DictReader(f) 첫 줄을 컬럼 이름으로 삼아 나머지를 딕셔너리로 바꿔줍니다. row["rating"] 처럼 이름으로 꺼낼 수 있게 됩니다.
list(...) with 를 벗어나면 파일이 닫혀서 못 읽습니다. 닫히기 전에 전부 꺼내 담습니다.
fieldnames=columns 쓸 칸과 순서를 여기서 정합니다. 목록에 없는 키는 그냥 빠집니다 — 구매 줄에서 후기가 사라지는 원리입니다.
lineterminator="\n" 줄 끝 문자. 안 적으면 윈도우와 맥에서 같은 입력에 다른 파일이 나옵니다.
f"R{number:04d}" 숫자를 네 자리로 채웁니다. 1 → "R0001". 후기에는 원래 번호가 없어서 여기서 만듭니다.
"content": row["review"] 이름을 바꿔 담는 유일한 칸. 파일 이름이 이미 reviews 라서 review.review 는 어색합니다.
"written_at": row["purchased_at"] 후기 작성일을 구매일과 같게 둡니다. 원본에 작성일이 없기 때문입니다.

호출 부분 — main

if "review" not in rows[0] 첫 줄에 review 칸이 없으면 이미 나눠놓은 것입니다. 딕셔너리에 in 을 쓰면 "키가 있는지" 를 봅니다.
return 함수를 여기서 끝냅니다. 덕분에 두 번 돌려도 안전합니다 — 이미 나뉜 파일을 또 나누면 후기가 사라집니다.
[make_purchase(row) for row in rows] 목록을 만드는 짧은 문법. "rows 의 줄마다 이 함수를 돌려 나온 값들로 목록을 만들어라".
enumerate(rows, start=1) 번호와 값을 함께 꺼냅니다. start=1 이라 1번부터. 이 번호가 R0001 의 재료입니다.
write_csv(PURCHASES, ...) 원본에 덮어씁니다. 후기 칸이 빠진 채로요. 바로 다음 줄에서 같은 함수로 reviews.csv 를 새로 만듭니다.
if __name__ == "__main__" 직접 실행했을 때만 main() 을 부릅니다. run_all.py 가 import 하면 함수만 가져가고 실행은 안 됩니다.

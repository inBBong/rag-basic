검색하고, 다시 줄 세웁니다

RAG 의 R(Retrieval)에 해당하는 폴더입니다. 파일 둘, 함수 다섯이 전부입니다.

질문 ↓ retriever.retrieve 질문을 벡터로 → 가까운 조각 20개 ↓ reranker.rerank AI 에게 물어 진짜 답 4개만 참고 자료
retriever.py retrieve · print_results · main
reranker.py pick_numbers · fill_up · rerank

왜 두 번 거르나

벡터 검색이 잘하는 것 단어와 뜻이 비슷한 글 찾기 벡터 검색이 못하는 것 그중 무엇이 질문의 답인지 고르기
"건성 피부에 쓸 토너 추천해줘" — 검색만 했을 때
    1  0.477  P103  사용법  비타민C 탄력 에센스 - 토너로 결을 정리한 뒤...
    2  0.466  P125  사용법  병풀 수분 에센스 - 토너로 결을 정리한 뒤...
    ...
    9  0.440  P121  사용법  녹차 수분 토너 - 세안 후 가장 먼저...   ← 정작 이게 답

에센스 사용법에 "토너로 결을 정리한 뒤" 라는 문장이 있어 단어가 겹친 것입니다. 점수도 1위와 9위가 0.037 차이뿐입니다.

후보를 20개로 넓히는 이유

10개로 뽑아보니 9개가 전부 "사용법" 섹션이었습니다. 리랭커는 검색이 안 가져온 글을 만들어내지 못합니다. 20개로 넓히니 다른 섹션이 섞여 들어왔고, 실제 토너를 골라냈습니다.

전용 리랭커 API 를 쓰지 않고 OpenAI 에게 물어봅니다. "이 중에 진짜 답이 되는 게 뭐야?" 라고요. 그러면 키가 하나로 유지되고 리랭킹 기준이 프롬프트에 그대로 드러납니다.

{{CODE:app/rag/reranker.py}}

import 부분

import re AI 답변에서 숫자만 뽑아내려고 씁니다.
from app.ai import llm, prompts DB 를 안 씁니다. 그래서 rerank 는 db 인자를 안 받습니다. 이미 찾아온 후보를 줄 세우기만 합니다.

왜 함수가 셋인가

AI 답변 "다음 순서입니다: 3, 0, 25, 3" ↓ pick_numbers 숫자만 뽑고, 범위 밖(25)과 중복(3) 버림 → [3, 0] ↓ fill_up 4개가 되게 원래 순서로 채움 → [3, 0, 1, 2] ↓ 번호를 청크로 되돌림

AI 가 시킨 대로 답하지 않을 때가 있습니다. "반드시 4개" 라고 적었는데 1개만 고르거나, 없는 번호를 주거나, 말을 붙입니다. 그걸 받아내는 함수가 둘 필요합니다.

pick_numbers

re.findall(r"\d+", answer) 글자 안의 모든 숫자 덩어리를 찾습니다. \d 는 숫자 하나, + 는 하나 이상. 결과는 글자 목록이라 int() 로 바꿉니다.
number < count 후보 개수보다 작은 것만. 번호는 0부터 시작하므로 후보가 20개면 0~19 만 유효합니다.
number not in numbers 같은 번호를 두 번 고르는 경우를 막습니다.

fill_up

range(count) 0, 1, 2, ... — 원래 검색 순서입니다.
if len(order) >= top_k: break 이미 충분히 채웠으면 그만합니다.
if number not in order AI 가 이미 고른 번호는 건너뛰고 안 고른 것 중 앞에서부터 채웁니다. 원래 검색 순서가 좋은 순서이기 때문입니다.
order.append(...) 받은 목록을 직접 고칩니다. 새 목록을 만들지 않습니다.

rerank — 본체

enumerate(chunks) 번호와 값을 함께 꺼냅니다. start 를 안 줘서 0부터 셉니다.
f"[{number}] {chunk['content']}" 각 후보 앞에 번호를 붙입니다. AI 는 이 번호로만 답하면 됩니다.
.format(top_k=top_k) 프롬프트의 {top_k} 자리에 숫자를 넣습니다. "...{top_k}개 고르세요" → "...4개 고르세요"
llm.ask(...) 7단계에서 만든 함수를 그대로 씁니다. 리랭킹 전용 코드가 따로 없습니다.
[chunks[n] for n in order[:top_k]] 번호를 실제 청크로 되돌립니다. AI 에게 글을 다시 쓰게 하지 않아서 내용이 변하지 않습니다.

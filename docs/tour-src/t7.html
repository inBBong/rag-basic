맨 위 — 요소와 대화 기록

document.getElementById(...) 한 번만 찾아 상수에 담아둡니다. 함수마다 다시 찾으면 느리고 코드도 길어집니다.

KEEP_TURNS = 3 최근 세 번만. 다 보내면 프롬프트가 길어지고 비용도 늘어납니다.

askServer — 조각을 이어 붙여 읽습니다

response.body.getReader() 응답을 흘러오는 대로 읽는 도구를 얻습니다. response.json() 은 다 올 때까지 기다려서 여기선 못 씁니다.
{ stream: true } 한글에 꼭 필요합니다. 한글 한 글자가 3바이트라 덩어리 경계에서 잘릴 수 있는데, 이 옵션이 잘린 바이트를 들고 있다가 합쳐줍니다.
buffer = parts.pop() 맨 마지막 조각은 다시 buffer 로 돌려놓습니다. 끝이 잘렸을 수 있어서, 다음에 온 것과 합쳐 씁니다.
part.slice(6) 앞의 "data: " 6글자를 떼어냅니다.
onEvent(...) 받은 것을 넘겨주기만 합니다. 읽는 일과 그리는 일을 나눠두면 각각이 짧아집니다.

그리는 함수들

className = "node " + route "node tool" 또는 "node rag" 가 됩니다. CSS 가 이 이름을 보고 색을 칠합니다.
answerBox.textContent += text = 가 아니라 += 입니다. 조각이 올 때마다 이어 붙여야 한 자씩 찍히는 것처럼 보입니다.
textContent 를 씁니다 innerHTML 이 아닙니다. 글자로만 넣어서 내용에 < 가 있어도 태그로 해석되지 않습니다.
history.slice(-KEEP_TURNS) 뒤에서 3개만 남깁니다. 음수는 뒤에서부터 센다는 뜻입니다.
if (result.route === "tool") 온 길에 따라 다르게 그립니다. DB 로 왔으면 조회 결과를, 검색으로 왔으면 글 조각을 보여줍니다.
JSON.stringify(row, null, 0) DB 조회 결과를 그대로 보여줍니다. 전화번호가 가려진 채 나오는 것을 눈으로 확인할 수 있습니다.

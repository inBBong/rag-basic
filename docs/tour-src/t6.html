채점 함수 넷

all(...) 전부 있어야 참. 키워드는 다 들어가야 합니다.
any(...) 하나만 있으면 참. 거절 표현은 여러 가지라서요.
앞의 셋은 AI 를 안 씁니다 글자 비교뿐이라 빠르고, 매번 같은 결과가 나옵니다.
re.findall(r"[1-5]", reply) 답에서 1~5 숫자만 뽑습니다. pick_numbers 와 같은 수법입니다 — AI 가 "4점입니다" 라고 답해도 4 를 얻습니다.
if numbers else 0 숫자를 하나도 안 주면 0점. 채점 자체가 실패한 경우입니다.

hit_for_one — 답을 미리 알고 채점

고객의 구매 내역 8건 ↓ 가장 최근 1건을 숨긴다 ← 이게 정답 ↓ 남은 7건으로 프로필을 만든다 ↓ 추천을 돌린다 ↓ 숨긴 상품이 나왔는가?
purchases[0] 구매 내역은 최근 순이라 맨 앞이 마지막 구매입니다. purchase_repository 의 order_by(...desc()) 에 기댑니다.
dict(detail, purchases=...[1:]) 원본을 복사하면서 첫 번째를 뺀 목록으로 바꿉니다. detail 자체는 그대로 남습니다.
reviews=...[1:] 후기도 하나 뺍니다. 안 빼면 숨긴 상품의 후기가 프로필에 남아서 정답을 알려주는 셈이 됩니다.
recommend_service.CANDIDATES 같은 상수를 씁니다. 40을 여기 다시 적으면 나중에 한쪽만 바뀌어 평가와 실제가 달라집니다.
len(purchases) < 2 → None 숨길 것이 없으면 "틀렸다" 가 아니라 "잴 수 없다" 입니다. 그래서 False 가 아니라 None 입니다.

{True: "O", False: "X", None: "-"} 딕셔너리로 값을 바꿉니다. if/elif/else 세 줄보다 한 줄이 읽기 쉽습니다.

테이블 다섯 개의 생김새

클래스 하나 = 테이블 하나, 클래스 변수 하나 = 컬럼 하나입니다. 이렇게 적어두면 SQLAlchemy 가 테이블을 만들어 주고, 조회 결과도 이 클래스의 객체로 돌려줍니다.

customer.py 고객 300명 정형
product.py 상품 200개 정형 비정형 — 한 테이블에 둘 다 있습니다
purchase.py 구매 이력 1,500건 정형
review.py 후기 1,500건 비정형
chunk.py 잘린 조각 3,060개 + 벡터 비정형
__init__.py 빈 파일이 아닙니다. 다섯 모델을 한 번에 불러옵니다.
customers ←─┐ │ └─ purchases ─→ products ←─ chunks └─── reviews ────→ products

지킨 규칙 셋

표준 타입만

String Integer Text Date 만 씁니다. DB 전용 타입을 쓰면 옮길 때 고쳐야 합니다.

파생 컬럼 없음

total_spend 같은 칸을 만들지 않습니다. 실제 회사 DB 에 없기 때문입니다.

관계 선언 없음

relationship() 을 안 씁니다. 필요할 때 Repository 에서 JOIN 으로 잇습니다.
